# Магазин №1 · 3D-планировка

Интерактивная 3D-модель торгового зала по технологической схеме. Открывается в браузере по ссылке, ничего устанавливать не нужно. Работает и на телефоне.

## Что умеет

- **Три режима просмотра:** «План» (вид сверху, как на схеме), «3D» (облет) и «Прогулка» (от первого лица, на высоте глаз 1,6 м).
- **Перестановка оборудования:** объект перетаскивается мышкой или пальцем с шагом 50 мм, клавиша `R` поворачивает на 90°, `Ctrl+Z` отменяет.
- **Двери и фасад:** проемы служебных помещений вырезаны по дугам открывания со схемы, у каждой двери коробка, полотно и табличка; на полу видна зона открывания. Кнопка «С улицы» показывает вход и фасад дома по фото из схемы, в «Прогулке» можно выйти на тротуар.
- **Товар на полках:** бутылки воды и вина, банки, пакеты молока, хлеб, сыры, мясо в лотках, фрукты в ящиках и т.д. Вид товара на каждой полке берется из категорий раскроя (`js/goods.js`).
- **Карточка объекта:** габариты, температурный режим, выкладка по категориям из раскроя, проход перед лицевой стороной.
- **Проверки:** пересечения со стенами и другим оборудованием, проходы уже 1200 мм, ширина путей эвакуации (1,0 м) и транспортного коридора (1,2 м, ориентир по легенде схемы).
- **Добавить:** оборудование из блока «Не удалось разместить» и типовые стеллажи.
- **Поделиться:** расстановка кодируется прямо в ссылке, коллега открывает ровно ваш вариант.
- **Excel:** выгрузка списка оборудования с координатами и обратная загрузка.

## Откуда данные

`data/store.json` собирается скриптом `tools/build_data.py` из PDF технологической схемы. Масштаб определен по 40 с лишним размерным цепочкам листа 3 (15,678 мм на пункт PDF, расхождение меньше 1 мм). Площадь пола по модели 97,9 м².

Высоты, которых нет на схеме, взяты типовые и помечены в карточке объекта. Сам PDF и коммерческие данные (адрес, финансовые показатели) в репозиторий не кладутся: сайт публичный.

```bash
pip install pymupdf shapely
python3 tools/build_data.py путь/к/схеме.pdf
```

## Устройство

Статический сайт без сборки: `index.html`, `js/app.js` (интерфейс и сцена), `js/build.js` (3D-геометрия), `js/goods.js` (товары), `js/checks.js` (проверки). Библиотеки лежат в `vendor/`: three.js 0.169 (MIT) и SheetJS 0.18.5 (Apache-2.0), поэтому сайт не зависит от внешних CDN.

Публикация: GitHub Pages из ветки `main`, корень репозитория.
